# Дыма нет — сайт-визитка

Одностраничный сайт на чистом HTML/CSS/JS. Для 18+.

## Публикация на GitHub Pages
1. Создайте аккаунт на github.com и нажмите **New repository** (например, `dyma-net`, Public).
2. Откройте репозиторий → **Add file → Upload files**.
3. Перетащите `index.html`, `.nojekyll` и папку `images/` (сохраняя структуру).
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В **Build and deployment** выберите **Deploy from a branch**, ветка **main**, папка **/ (root)**, **Save**.
7. Подождите 1–2 минуты, пока завершится сборка (вкладка Actions).
8. Сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/dyma-net/`.

Фото и логотип лежат в `images/` (hero.jpg, about.jpg, logo.png). Чтобы заменить, положите файл с тем же именем.

Ссылку на карточку в 2ГИС меняйте в `index.html` в блоке «Контакты» (кнопка `id="link2gis"`).
